LAN Share

Phone ⇄ PC, no internet needed

Send files and text between your own devices on the same WiFi. It runs on your PC: no accounts, no database, nothing leaves your network.

Download Read the setup guide Source code

What it does

Files and textSend photos, videos, documents and notes. Scan a QR code on your PC and your phone is connected.
Big files, flaky WiFiUploads go up in pieces and carry on from where they stopped if the connection drops. Zip several files at once.
Folders and previewsGroup files into folders, switch between grid and list, sort, and preview images, video, audio and PDFs.
Send to one deviceMake a file or note visible only to the device you pick.
You control who joinsSee connected devices, rename them, revoke or block them, and ask for approval or a 4-digit PIN before a new device joins.
Dark and lightWorks on phone and desktop. Installable to the home screen, with an optional encrypted address.

Run it in a minute

  1. Install Node.js (version 18 or newer).
  2. Download and unzip LAN Share, then double-click start.bat (or run node server.js).
  3. Your browser opens. Open the Scan QR panel and scan the code with your phone camera.

Want it from anywhere? The setup guide has a step-by-step for Tailscale, a free private network between your own devices.

Why this page can't run the app. LAN Share needs a small server running on your own PC to store and hand over your files. This page is only a description. It is not meant for the public internet: there is no login, so run it on your home WiFi or over Tailscale.
